# Changelog

All notable changes to the **DeepAI Post Generator** plugin will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] — 2026-03-21

### Added
- OpenAI API integration (GPT-4o, GPT-4 Turbo, GPT-4, GPT-3.5 Turbo)
- OpenRouter API integration (100+ models)
- Content generation with 4 article types: Standard, Listicle, How-To, Review
- AI image generation using DALL-E 3 (featured images + in-content images)
- Prompt template management system with dynamic placeholders
- SEO internal linking — auto-inserts contextual links to existing posts
- SEO external linking — AI-suggested authoritative external links
- Generation history with token usage, model info, and status tracking
- AES-256-CBC encrypted API key storage using WordPress security salts
- Multilingual content generation in 16 languages
- 7 writing tone options (Professional, Casual, Academic, Conversational, Humorous, Formal, Friendly)
- Content regeneration with custom instructions
- Modern responsive admin interface with card-based design
- One-click Save as Draft or Publish workflow
- WordPress REST API endpoints under `deepai/v1/`
- Full i18n support with English, Spanish (es_ES), and Portuguese (pt_BR) translations
- API connection testing from the Settings page
- Dynamic model loading from API providers
